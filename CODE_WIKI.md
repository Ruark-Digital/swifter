# SwiftPro eProcurement Portal - Code Wiki

## 1. Overall Project Architecture

SwiftPro is a modern, modular Single Page Application (SPA) designed for scalable eProcurement operations.

- **Frontend Framework**: React 19 + Vite + TypeScript.
- **State Management**:
  - **Client State**: Zustand (with auto-selectors and persistence) handles global states like authentication.
  - **Server State**: TanStack React Query handles data fetching, caching, and synchronization.
- **Routing**: React Router v6 provides public and protected route guards.
- **Styling**: Tailwind CSS v4 combined with Radix UI and custom Shadcn-style components.
- **API Communication**: Axios singleton instance wrapped with custom HTTP methods and interceptors for token injection and 401 handling.
- **Form Management**: A custom internal library called `Forge` (built on top of `react-hook-form` and `yup`) that provides cross-platform (Web & React Native) form handling.
- **Collaboration**: Yoopta Editor integrated with Yjs and WebSockets (`y-websocket`) for real-time rich-text document collaboration.
- **Error Tracking**: Sentry for error boundaries and session replays.

## 2. Responsibilities of Major Modules

- **`src/components/`**: Reusable UI primitives and layout components.
  - `ui/`: Generic elements like buttons, inputs, dialogs, and tables.
  - `layouts/`: Higher-order structural components such as `DataTable`, `Dashboard`, `AuthorityGuard`, and `SEOWrapper`.
- **`src/pages/`**: Feature-specific domains. Each feature contains its own components, API calls, layouts, and tests.
  - `ContractManagementPage`: Manages contracts, amendments, claims, invoices, NCRs, and RFIs.
  - `SolicitationManagementPage`: Handles RFPs, bidding, proposals, and message threads.
  - `EvaluationManagementPage`: Vendor scoring, criteria scorecards, and consensus.
  - `VendorManagementPage` & `OnboardingPage`: Vendor profiles, onboarding workflows, and submissions.
  - `CollaborationToolPage`: Real-time document editing and activity logging.
- **`src/lib/`**: Core utilities and structural abstractions.
  - `axiosInstance.ts`: Centralized HTTP client and request wrappers.
  - `forge/`: The cross-platform form architecture.
- **`src/store/`**: Global state definitions.
  - `authSlice.ts`: Manages JWT tokens, user metadata, and authority levels.
- **`src/hooks/`**: Reusable custom React hooks.
  - `useUserRole.ts`: Derives role flags (e.g., `isVendor`, `isApprover`, `isCompanyAdmin`).
  - `useAuthentication.ts`: Verifies active session states.

## 3. Descriptions of Key Classes and Functions

- **`axiosInstance.ts` (API Layer)**
  - `getRequest`, `postRequest`, `putRequest`, `deleteRequest`: Abstracted generic functions that automatically attach `Authorization` headers. They are strictly enforced by workspace rules (developers must not use `axios` directly).
- **`authSlice.ts` (Zustand Store)**
  - `useUser()`, `useToken()`, `useAuthorities()`: Hook selectors generated by `auto-zustand-selectors-hook` to access auth state.
  - `setReset()`: Clears the session entirely; automatically triggered by the Axios response interceptor on `401 Unauthorized`.
- **`AuthorityGuard` (`src/components/layouts/AuthorityGuard/index.tsx`)**
  - A layout guard that checks `useAuthentication()`. If a user lacks a valid token or session, it redirects them to the public login screen.
- **`contractManagerApi` (`src/pages/ContractManagementPage/api/contractManagerApi.ts`)**
  - A comprehensive service object containing strongly typed methods (e.g., `createContract`, `approveChange`, `listLems`) for interacting with the backend contract endpoints.
- **`Forge` & `Forger` (`src/lib/forge/`)**
  - **`Forge`**: The main form wrapper component that supplies the `react-hook-form` context.
  - **`Forger`**: A field renderer that automatically maps the correct event handlers (`onChange` vs `onChangeText`) based on whether the environment is Web or React Native.
- **`App.tsx`**
  - The application root. Initializes `QueryClientProvider`, `RouterProvider`, `ThemeProvider`, and the `Sentry.ErrorBoundary`. It also contains the custom `handleAIChatMessage` logic for streaming AI assistant responses via Server-Sent Events (SSE).

## 4. Dependency Relationships

- **UI & Presentation**: `tailwindcss`, `@radix-ui/react-*`, `lucide-react`, `recharts` -> Build the visual layer.
- **Routing & State Pipeline**: `react-router-dom` -> renders pages -> pages use `zustand` (client state) and `@tanstack/react-query` (server state).
- **Data Fetching Pipeline**: `useQuery` / `useMutation` -> calls feature API (e.g., `contractManagerApi`) -> calls `postRequest` / `getRequest` -> uses `axiosInstance`.
- **Forms Pipeline**: `<Forge>` -> uses `react-hook-form` + `@hookform/resolvers/yup` -> validates against `yup` schemas.
- **Collaboration Pipeline**: `@yoopta/editor` -> synced via `yjs` + `y-websocket` -> provides real-time multi-user editing.
- **Testing & Quality Assurance**: `@playwright/test` for E2E suites located within `__tests__` folders, and `@sentry/react` for telemetry.

## 5. Instructions for Running the Project

### Prerequisites
- **Node.js**: v18 or higher.
- **Package Manager**: `npm` (or `pnpm` as defined in workspace rules).

### Setup & Execution
1. **Install Dependencies**:
   ```bash
   npm install
   ```
2. **Environment Variables**:
   Create a `.env` file in the root directory (refer to `.env.example`).
   ```env
   VITE_API_BASE_URL=https://dev.swiftpro.tech/api/v1/dev
   VITE_SENTRY_DSN=your_sentry_dsn_here
   ```
3. **Run Development Server**:
   ```bash
   npm run dev
   ```
   The app will be available at `http://localhost:5173`.
4. **Build for Production**:
   ```bash
   npm run build
   ```
5. **Linting**:
   ```bash
   npm run lint
   ```

### Testing
The project uses Playwright for End-to-End testing.
1. **Install Browsers**:
   ```bash
   npx playwright install
   ```
2. **Run All Tests**:
   ```bash
   npm test
   ```
3. **Run Specific Suites**:
   ```bash
   npm run test:companies
   npm run test:contract
   npm run test:evaluation
   ```
4. **Run Tests with UI**:
   ```bash
   npm run test:ui
   ```
